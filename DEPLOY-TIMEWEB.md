# Публикация полной версии в Timeweb Cloud

Настройки предназначены для владельца или администратора хостинга. Посетителям сайта регистрация не нужна.

## База

Создайте PostgreSQL в российском регионе, базу и пользователя с правами на создание таблиц. Сайт и базу разместите в одном регионе. Получите строку подключения из панели и сохраните в DATABASE_URL. Специальные символы имени и пароля должны быть закодированы для URL. Сохраните параметры TLS; при необходимости подключите корневой сертификат через PGSSLROOTCERT. Проверка сертификатов не отключается.

## Приложение

Подключите репозиторий smirnovairina7090-blip/creitivika-knowledge, ветку main. В App Platform выберите фреймворк Dockerfile, российский регион и оставьте путь к директории проекта пустым. Dockerfile в корне уже содержит сборку и запуск полного приложения на Node.js 24 и EXPOSE 3000. Внешний HTTPS обслуживает хостинг. Папка docs предназначена только для GitHub Pages.

Не выбирайте статический frontend-тариф Next.js: для вопросов и ответов нужны серверные обработчики. Для переноса используется Dockerfile по официальной инструкции хостинга.

На доверенном компьютере выполните npm run setup:code. Сохраните выведенные KB_EDITOR_CODE_HASH и KB_SESSION_SECRET в переменных приложения на хостинге. Эти значения и DATABASE_URL не добавляются в GitHub. Код команды требуется только методистам.

| Переменная | Значение |
| --- | --- |
| DATABASE_URL | Строка подключения PostgreSQL |
| KB_EDITOR_CODE_HASH | Хеш из setup:code |
| KB_SESSION_SECRET | Секрет из setup:code |
| PORT | 3000 |
| NEXT_TELEMETRY_DISABLED | 1 |
| KB_PUBLIC_ORIGIN | Выданный HTTPS-адрес сайта без пути и завершающего слеша |

Если адрес выдаётся после первого запуска, добавьте KB_PUBLIC_ORIGIN после его получения и перезапустите приложение. Параметр обеспечивает проверку источника запросов и Secure-cookie за обратным прокси.

Для раздельных ограничений отправки вопросов нужен доверенный адрес клиента от прокси. После проверки заголовков хостинга задайте KB_CLIENT_IP_HEADER (например, x-forwarded-for, если прокси гарантированно добавляет адрес клиента справа). При отсутствии доверенного заголовка отправки ограничиваются общим лимитом. Произвольные заголовки клиента не используются для контроля доступа.

Путь проверки состояния: /api/health. При запуске автоматически применяются миграции из db/migrations. Новые изменения схемы добавляются отдельными файлами; уже применённые файлы не редактируются. Если приложение не запускается, проверьте переменные, доступ к базе и права PostgreSQL.

Размещение приложения и PostgreSQL оплачивается по тарифам хостинга. Сверьте итоговую стоимость перед заказом. Свой домен для первого запуска не обязателен: можно использовать технический адрес Timeweb с HTTPS.

## Проверка

Откройте сайт без входа в хостинг, отправьте вопрос преподавателя и сохраните личную ссылку. В другом браузере войдите по коду команды, ответьте и проверьте ответ по личной ссылке. Отправьте уточнение и проверьте возврат вопроса в работу. Убедитесь, что без личной ссылки вопрос недоступен.

Проверьте адрес с телефона через домашнюю сеть и мобильный интернет без VPN. Отдельно проверяются внешние ссылки на тренажёры: доступность зависит от соответствующих сервисов.

Перед переключением с Vercel/Neon экспортируйте PostgreSQL и импортируйте данные в новую базу, сохранив идентификаторы, хеши личных ключей и таблицу миграций. Сохраните прежние KB_EDITOR_CODE_HASH и KB_SESSION_SECRET в настройках нового приложения, если код команды должен остаться прежним. Секреты и дамп не добавляются в GitHub.

Личные ссылки содержат идентификатор и ключ после символа #. Для нового сайта меняется только адрес до #; сохранение хешей ключей в базе позволяет продолжить доступ к прежнему вопросу. Список «Мои вопросы» и избранное хранятся в браузере и автоматически на другой домен не переносятся. После проверки переноса обновите адрес переадресации в docs/index.html и README.md. Текущий Vercel оставьте работающим до проверки новой базы.

Официальные инструкции: https://timeweb.cloud/docs/apps/deploying-with-dockerfile и https://timeweb.cloud/docs/dbaas/dbaas-create.
