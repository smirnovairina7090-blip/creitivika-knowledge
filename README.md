# База знаний Креайтивики

Next.js-приложение с карточками ситуаций, поиском, избранным, каталогом сервисов и вопросами преподавателей. Полная версия использует сервер Node.js и PostgreSQL. Код размещён в GitHub; публикация приложения на хостинге настраивается отдельно.

Преподавателю не нужна регистрация: после отправки вопроса он получает личную ссылку с доступом к своему ответу и уточнениям. Избранное и сохранённые личные ссылки привязаны к браузеру. Методист входит по коду команды, видит общую очередь и отвечает. Подписка работает внутри сайта, отправка писем и push-уведомлений не подключена.

## Полная версия на Timeweb Cloud

Настройки: [DEPLOY-TIMEWEB.md](DEPLOY-TIMEWEB.md). Поддерживаются Next.js с SSR и сборка через Dockerfile. Таблицы PostgreSQL автоматически создаются при npm run start, существующие данные сохраняются. DATABASE_URL и секреты задаются в панели хостинга и не добавляются в GitHub.

## Запуск

Нужен Node.js 24 и PostgreSQL. Выполните npm ci, затем npm run setup:code. Сохраните DATABASE_URL, KB_EDITOR_CODE_HASH и KB_SESSION_SECRET в переменных окружения. Дополнительные параметры перечислены в .env.example.

Соберите приложение командой npm run build, запустите npm run start. Для разработки предварительно выполните npm run db:migrate, затем npm run dev. Переменные должны быть доступны процессу: можно использовать node --env-file=.env.local scripts/start.mjs. Файл .env.local исключён из Git.

/api/health возвращает 200, когда доступны база и настройки команды. Этот адрес не раскрывает данные подключения.

## GitHub Pages

Статическая версия собрана в папке docs. В настройках Pages выберите Deploy from a branch, ветку main и папку /docs. Доступны карточки, поиск, копирование сообщений, избранное и каталог сервисов. Отправка вопросов, ответы методиста и редактирование в этой версии отключены с пояснением: для них требуется полная серверная версия.

Обновление статической версии: npm ci, затем npm run build:pages. При изменении названия репозитория обновите base в vite.pages.config.ts.

## Данные прежнего сайта

В репозиторий включены исходные карточки и каталог сервисов. Сохранённые в рабочей базе изменения, вопросы, ответы и секреты прежнего сайта не экспортированы. Для переноса этих данных нужен отдельный экспорт и импорт. Не закрывайте прежний сайт до завершения переноса. Старые личные ссылки продолжают указывать на прежний адрес.

## Проверки

npm run typecheck проверяет TypeScript, npm run build собирает полную версию, node scripts/verify-database.mjs проверяет миграции и сценарии вопросов на временной базе PGlite. Блокировка миграций в реальном PostgreSQL и опубликованный сайт проверяются после подключения хостинга.
