# База знаний Креайтивики

Next.js-приложение с карточками ситуаций, поиском, избранным, каталогом сервисов и вопросами преподавателей. Полная версия использует сервер Node.js и PostgreSQL. Код размещён в GitHub.

Преподавателю не нужна регистрация: после отправки вопроса он получает личную ссылку с доступом к своему ответу и уточнениям. Избранное и сохранённые личные ссылки привязаны к браузеру. Методист входит по коду команды, видит общую очередь и отвечает. Подписка работает внутри сайта, отправка писем и push-уведомлений не подключена.

## Полная версия на Timeweb Cloud

Настройки: [DEPLOY-TIMEWEB.md](DEPLOY-TIMEWEB.md). В App Platform выберите Dockerfile и российский регион: файл сборки полного приложения уже включён в репозиторий. Таблицы PostgreSQL автоматически создаются при npm run start. Для переноса существующих вопросов из Neon сначала нужен экспорт и импорт базы. DATABASE_URL и секреты задаются в панели хостинга и не добавляются в GitHub.

## Версия на Vercel

Адрес: https://creitivika-knowledge.vercel.app. Пользователь сообщил о недоступности из России без VPN, поэтому этот адрес не удовлетворяет требованию доступности. Версия для переноса на российский хостинг подготовлена, но пока не опубликована там. PostgreSQL подключён через Neon. vercel.json задаёт сборку с предварительным применением миграций; повторный запуск не удаляет существующие данные. На Vercel не используется npm run start.

В Production должны быть заданы DATABASE_URL, KB_EDITOR_CODE_HASH, KB_SESSION_SECRET, KB_PUBLIC_ORIGIN=https://creitivika-knowledge.vercel.app и KB_CLIENT_IP_HEADER=x-vercel-forwarded-for. Секреты хранятся только в панели проекта. Преподавателям не нужен аккаунт Vercel или Neon.

Hobby предназначен для личных некоммерческих проектов. Для регулярного использования в коммерческой школе нужен подходящий тариф Vercel или другой хостинг. Работу без VPN проверяют на устройствах пользователей после публикации.

## Запуск

Нужен Node.js 24 и PostgreSQL. Выполните npm ci, затем npm run setup:code. Сохраните DATABASE_URL, KB_EDITOR_CODE_HASH и KB_SESSION_SECRET в переменных окружения. Дополнительные параметры перечислены в .env.example.

Соберите приложение командой npm run build, запустите npm run start. Для разработки предварительно выполните npm run db:migrate, затем npm run dev. Переменные должны быть доступны процессу: можно использовать node --env-file=.env.local scripts/start.mjs. Файл .env.local исключён из Git.

/api/health возвращает 200, когда доступны база и настройки команды. Этот адрес не раскрывает данные подключения.

## GitHub Pages

Папка docs содержит страницу переадресации на полную версию https://creitivika-knowledge.vercel.app. Прежний адрес https://smirnovairina7090-blip.github.io/creitivika-knowledge/ продолжает работать. В настройках Pages используются ветка main и папка /docs.

Для отдельной статической копии: npm ci, затем npm run build:pages. Эта команда заменяет переадресацию статической сборкой: в ней доступны карточки и каталог, а вопросы и редактирование требуют серверной версии. При изменении названия репозитория обновите base в vite.pages.config.ts.

## Данные прежнего сайта

В репозиторий включены исходные карточки и каталог сервисов. Сохранённые в рабочей базе изменения, вопросы, ответы и секреты прежнего сайта не экспортированы. Для переноса этих данных нужен отдельный экспорт и импорт. Не закрывайте прежний сайт до завершения переноса. Старые личные ссылки продолжают указывать на прежний адрес.

## Проверки

npm run typecheck проверяет TypeScript, npm run build собирает полную версию, node scripts/verify-database.mjs проверяет миграции и сценарии вопросов на временной базе PGlite. Миграции успешно применены к подключённому PostgreSQL. На опубликованном сайте проверены отправка вопроса через форму, сохранение ответов, личные ссылки, уточнения, уведомление о новом ответе и запрет доступа без ключа.
