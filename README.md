# База знаний Креайтивики для Netlify

Сохранены карточки ситуаций, 26 сервисов и упражнений, поиск, избранное, вопросы преподавателей, личные ссылки, подписки внутри сайта и ответы методистов по коду команды.

Посетителям не нужны регистрация, аккаунт ChatGPT или аккаунт Netlify. Владелец проекта регистрируется в Netlify один раз. Перед передачей ссылки преподавателям проверьте открытие опубликованного адреса без входа в аккаунт.

## Размещение проекта в GitHub

Создайте отдельный репозиторий creitivika-knowledge и добавьте README, чтобы в нём появилась ветка main. Загрузите файлы проекта в корень репозитория. Не загружайте node_modules, .next, .env.local или значения секретов. Затем подключите этот репозиторий в Netlify через Import from Git.

GitHub хранит код проекта. Для серверной обработки вопросов и общей базы используется Netlify.

## Публикация

Это исходный проект Next.js с серверной частью. Обычная загрузка папки через Netlify Drop без сборки не подходит.

1. Распакуйте архив и откройте папку проекта в терминале. Нужен Node.js 24.
2. Выполните `npm ci`.
3. Выполните `npm run setup:code`, задайте код команды и сохраните выведенные значения для настройки проекта. Эти значения не добавляйте в открытые файлы или репозиторий.
4. Выполните `npx netlify-cli login` и завершите вход в браузере.
5. Создайте проект командой `npx netlify-cli sites:create` и свяжите папку с ним командой `npx netlify-cli link`.
6. В настройках проекта добавьте переменные KB_EDITOR_CODE_HASH и KB_SESSION_SECRET для Functions. Включите Netlify Database. Проверьте тариф и лимиты в своём аккаунте, прежде чем включать платные дополнения.
7. Выполните `npx netlify-cli deploy --build --prod`. Команда собирает Next.js с адаптером Netlify. Миграция в netlify/database/migrations создаёт таблицы новой базы при поддерживаемом процессе публикации; если CLI не применил её, примените SQL через интерфейс Database перед проверкой вопросов.
8. В настройках доступа переключите проект в публичный режим, если он создан закрытым. Посетителям вход не нужен.
9. Проверьте отправку вопроса, сохранение личной ссылки, вход методиста по коду, запись ответа и его чтение в другом браузере.

Если используете Git: загрузите этот проект в свой репозиторий и выберите Import from Git в Netlify. Команда сборки `npm run build`, папка публикации `.next`. Настройки заданы в netlify.toml.

## Данные из прежнего сайта

В архив включены исходные карточки и каталог сервисов. В архив НЕ включены сохранённые в рабочей базе изменения, вопросы, ответы и секреты прежнего сайта: доступ к этой базе не предоставлен. Эти данные необходимо отдельно экспортировать и импортировать перед окончательным переключением.

Личные ссылки ранее отправленных вопросов остаются на старом адресе до переноса соответствующих записей и хешей доступа. Мои вопросы и избранное хранятся в браузере отдельно для каждого адреса. Не закрывайте прежний сайт до завершения переноса.

## Проверка

`npm run typecheck` проверяет TypeScript, `npm run build` собирает приложение. `node scripts/verify-database.mjs` проверяет PostgreSQL-адаптер на отдельной временной базе PGlite. Эти проверки не заменяют проверку опубликованного приложения с Netlify Database.
